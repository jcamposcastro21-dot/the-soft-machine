Cómo obtener tu token de GitHub (una sola vez)

Usa un token clásico, no uno "fine-grained": los fine-grained no tienen acceso completo a la API que usa este panel para publicar (da error 403).

  1. Ve a github.com/settings/tokens/new (mientras tengas sesión iniciada).
  2. Note: cualquiera, ej. "the-soft-machine-admin".
  3. Expiration: la que prefieras (ej. 90 días).
  4. Scopes: marca public_repo (alcanza porque el repo es público).
  5. Click "Generate token" y cópialo (empieza con ghp_...). Solo se muestra una vez.
  6. Pégalo abajo. Si marcas "recordar", queda guardado solo en este navegador (nunca se envía a ningún lado excepto a GitHub).
