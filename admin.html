Cómo obtener tu token de GitHub (una sola vez)

  1. Ve a github.com/settings/personal-access-tokens/new (mientras tengas sesión iniciada).
  2. Nombre: cualquiera, ej. "the-soft-machine-admin".
  3. Repository access: "Only select repositories" → elige the-soft-machine.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Genera el token y cópialo (empieza con github_pat_...). Solo se muestra una vez.
  6. Pégalo abajo. Si marcas "recordar", queda guardado solo en este navegador (nunca se envía a ningún lado excepto a GitHub).
